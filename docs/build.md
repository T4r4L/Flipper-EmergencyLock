# Build

## Host prototype

Prerequisites: CMake 3.16 or later and a C11 compiler supported by CMake.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
ctest --test-dir build --output-on-failure
```

The project has no third-party source dependencies. The workflow in `.github/workflows/ci.yml` installs the host build tools and runs these steps on Ubuntu.

## Firmware build status

There is no Flipper application manifest, firmware fork, or firmware target in this repository. Consequently, `fbt`, `ufbt`, the complete firmware build, and a standard update package are not currently applicable. Do not rename the host test binary as a firmware artifact.

For future application work, the official developer documentation describes [uFBT](https://developer.flipper.net/flipperzero/doxygen/fbt.html), [FAP builds](https://developer.flipper.net/flipperzero/doxygen/apps_on_sd_card.html), and the official firmware [build system](https://github.com/flipperdevices/flipperzero-firmware). Pin an exact source commit, verify the FAP/API version, and build against the matching SDK. A standalone FAP cannot satisfy the device-wide lockdown requirement.

## Reproducibility

CI uses CMake and the runner's C compiler; the compiler version is printed in the job log. For a bit-for-bit build, pin the operating-system image and compiler toolchain as well. No firmware binaries or release packages are generated by CI.
